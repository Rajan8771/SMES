SMES - why "127.0.0.1 refused to connect" happens
================================================

ERR_CONNECTION_REFUSED means SMES is NOT running on the computer
where Chrome is open.

Cursor Cloud / this chat cannot open on your office LAN.
You must start SMES on YOUR Windows PC (IPv4 172.24.88.169).

STEPS (same PC where you open Chrome)
-------------------------------------
1. Unzip smes-source.zip to a folder, for example:
   C:\Users\YourName\Downloads\smes-source

2. Open that folder. You must see:
   start-lan.bat
   start-here.bat
   requirements.txt
   smes\
   static\

3. Right-click start-here.bat -> Run as administrator

4. Keep the black window OPEN. Do not close it.

5. On THIS same PC, open Chrome:
   http://127.0.0.1:8000

6. Other users on the SAME office network open:
   http://172.24.88.169:8000

If step 5 still refuses:
- The black window closed or showed an error
- Open start-log.txt in the same folder and read the error
- Install Python from https://www.python.org/downloads/
  and tick "Add python.exe to PATH", then run start-here.bat again

Do NOT type 127.0.0.1 on other phones/PCs.
Do NOT expect Cursor Cloud http://127.0.0.1:8000 to work on your laptop.
