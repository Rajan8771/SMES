# SMES

Manufacturing execution issues and follow-up live in GitHub Issues on this repository.

## File an item

- [MES issue](https://github.com/Rajan8771/SMES/issues/new?template=mes-issue.yml) for a line, station, order, quality, or data problem.
- [MES tracking](https://github.com/Rajan8771/SMES/issues/new?template=mes-tracking.yml) for a lot, hold, or corrective action that needs an owner and a next check.

Open issues are the queue: https://github.com/Rajan8771/SMES/issues

Use `Rajan8771/SMES` for this work. `Rajan8771/git` is a fork of Git and is not the MES tracker.
