# Rajan Suman

3D profile for Rajan Suman, MES Software Engineer (`rj_suman_mes`).

The page is built from the public CV: OPPO Mobiles India SMT work from Jan 2021, RF engineering from Sept 2015 to Dec 2020, skills, two projects, education, and contact in Alfa-II, Greater Noida.

Anyone can download the CV from the hero, the navigation, and the contact card. The file is `public/Rajan-Suman-Resume.pdf`. The browser saves it as `Rajan Suman_Resume_P2.pdf`.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
